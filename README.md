# counterfactual_football_intelligence

In modern football, players constantly make decisions under changing spatial and tactical conditions, such as whether to pass, carry the ball, or take a shot. Although large amounts of match event data are available, conventional football analytics primarily focuses on describing what happened rather than evaluating the quality of the decision made in the specific context in which it occurred.

The problem is to develop a data-driven system that can analyze player decisions using event data and 360-degree spatial information. The system will reconstruct sequences of player actions, incorporate the positions of teammates and opponents, pressure, player location, and other contextual factors, and use these features to estimate the outcome or value of a player's decision.

The system will further explore counterfactual decision analysis by generating plausible alternative actions available in a given game state and comparing their estimated values with the actual action taken. This can provide deeper insight into player decision-making and identify situations where alternative choices may have produced more favorable outcomes.

The proposed system aims to move beyond basic statistical analysis by combining football event analytics, spatial data, machine learning, and counterfactual analysis to provide an explainable assessment of player decision-making.
